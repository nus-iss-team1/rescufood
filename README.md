# RescuFood

RescuFood replaces inefficient, fragmented communication (calls, chats, and spreadsheets) with a reliable, real-time digital workflow. It ensures time-sensitive surplus food is discovered, claimed, and tracked seamlessly without double allocations or missed pickups.

A NUS-ISS Team 1 project.

## Repository layout

| Folder | What's in it |
|---|---|
| [`frontend/`](frontend/README.md) | Next.js web client (setup guide inside) |
| [`infrastructure/`](infrastructure/README.md) | AWS CloudFormation stacks (network, security, identity, ECS) |
| `backend/` | NestJS API — coming in a later sprint |

## Quick start

```sh
cd frontend
npm install
npm run dev
```

See [`frontend/README.md`](frontend/README.md) for environment setup and sign-in configuration.
